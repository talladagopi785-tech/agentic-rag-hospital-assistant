# Agentic RAG Hospital Assistant

Lightweight FastAPI + Agentic RAG hospital search and appointment assistant.

Features: hospital search, specialty search, appointment booking/cancellation/listing, lightweight deterministic vector retrieval, low-memory Render deployment.

Render Build: `pip install -r requirements.txt`

Render Start: `uvicorn app:app --host 0.0.0.0 --port $PORT`
